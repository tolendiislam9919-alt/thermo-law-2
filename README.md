# Жылу үдерістерінің қайтымсыздығы. Термодинамиканың екінші заңы — 8-сынып

Ашық сабаққа арналған интерактивті слайд (физика, 8-сынып, оқу мақсаты 8.3.2.18).
Мұғалім: Төленді И.Н., «Тайтөбе ауылының жалпы орта білім беретін мектебі» КММ.

## Мүмкіндіктері
- 19 бет: мақсат → ЖИ-бот (Физбот) топқа бөледі → миға шабуыл → анимациялық видео → жаңа сабақ → бекіту
- Оқушылар QR арқылы телефонмен кіреді; ФС тапсырмалары телефонда өзі тексеріледі
- Топтық 3D квест: 3 бөлме, бірінші тұлғадан, телефон – джойстик, есептерден есіктің кодын табу
- Журнал: топ ұпайы + жеке ұпай → баға автоматты түрде; Excel-ге жүктеу, басып шығару
- Физботтың қазақша дауысы (`audio/`), интернетсіз де жұмыс істейді

## Ашу
- GitHub Pages: `https://<пайдаланушы>.github.io/termodinamika-2-zan-8-synyp/`
- Интернетсіз (Wi-Fi роутер): репозиторийді жүктеп алып, `start.bat` ашу (Python керек). Телефондар компьютермен бір Wi-Fi-да болсын.
- Сабақ алдында 17-беттегі журналға сынып тізімін бір рет жазып, «Тізімді сақтау» басыңыз:
  оқушылардың аты-жөні сайтта сақталмайды, тек мұғалімнің браузерінде тұрады.

## Файлдар
- `index.html` — сабақ; `?r=БӨЛМЕ` сілтемесімен ашылса – оқушы телефоны
- `phone_panel.js`, `oqushy.js` — мұғалім мен оқушы жағы
- `net.js`, `mqtt.min.js`, `qrcode.min.js` — байланыс және QR
- `three.min.js` — 3D квест (three.js r128)
- `audio/` — Физботтың дауысы
- `server.py`, `start.bat` — интернетсіз Wi-Fi арқылы ашу (жергілікті сервер)
- `NUSQAULYQ.txt` — мұғалімге толық нұсқаулық
- `.nojekyll` — GitHub Pages файлдарды өзгертпей беруі үшін
